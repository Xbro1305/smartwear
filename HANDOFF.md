# Умная Одежда (smartwear) — хендофф для продолжения

Фронтенд интернет-магазина: React 18 + TypeScript + Vite 6, Redux Toolkit + RTK Query,
React Router 6 (createBrowserRouter), Tailwind + MUI + Radix, SCSS-модули. FSD-структура
(`app / pages / widgets / entities / shared`). Прод: **Ubuntu + nginx** (`/var/www/front` или
`/root/front`, отдаёт `dist/`). API: `https://test.maxiscomfort.ru/api` (в `.env`).

Проверка: `npx tsc --noEmit` и `npm run build`. **На сервере ставить деп через
`npm install --legacy-peer-deps`** (иначе конфликты peer-deps и битый `lodash-es`).
Локально API за CORS — динамические блоки (товары/новости/магазины) пустые, видно только на сервере.
